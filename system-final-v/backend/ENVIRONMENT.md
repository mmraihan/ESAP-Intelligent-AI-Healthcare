# ESAP backend — environment variables

Every variable the backend reads, what it does, and its default. Set them in
`backend/.env` (gitignored) or as real environment variables.

## How `.env` is loaded

`app/config.py` reads `backend/.env` once, at import:

- **Real environment variables win** over `.env`.
- **The first occurrence of a key wins.** A duplicated key is silently ignored —
  keep exactly one line per variable. (A `.env` with two `LLM_BASE_URL` lines
  uses the first one.)
- Changes need a **restart**. `uvicorn --reload` watches `.py` files, not `.env`.
  In production: `systemctl restart esap-backend`.
- Quotes around values are stripped; lines starting with `#` are comments.

Never commit `.env`, and never paste real keys into chats, tickets or docs.

## Core

| Variable | Default | Purpose |
|---|---|---|
| `MODEL_MODE` | `stub` | `stub` = deterministic, contract-correct placeholder predictions; runs anywhere. `real` = load the trained model bundles from `ESAP_EXPORTS_DIR`. `/readyz` reports which is active. |
| `ESAP_EXPORTS_DIR` | *(unset)* | Path to the `model_exports/` handoff (read-only). Only used when `MODEL_MODE=real`. Relative paths resolve from `backend/`. |
| `ESAP_DB_PATH` | `esap.db` | SQLite file. Relative paths resolve from `backend/`. Wiped and rebuilt by `python -m app.seed --reset`. |
| `ESAP_SEED_PATH` | `seed/seed.json` | Demo dataset used by the seeder. Generated by the frontend (`npm run seed:dump`). |
| `ESAP_SECRET` | random per process | Signs session tokens. **Set it in production** — if unset, every restart signs everyone out. Use a long random value (`python -c "import secrets;print(secrets.token_hex(32))"`). |

## Browser access (CORS)

| Variable | Default | Purpose |
|---|---|---|
| `ESAP_CORS_ORIGINS` | `http://localhost:5175,http://127.0.0.1:5175` | Comma-separated origins allowed to call the API. Production must include the frontend, e.g. `https://esap-intelligent-ai-healthcare-r6cz.vercel.app`. |
| `ESAP_CORS_ORIGIN_REGEX` | `http://(localhost\|127\.0\.0\.1)(:\d+)?` | Extra origins by pattern (any local port, since Vite moves off 5175 when it is busy). Set to an empty value to turn off. |

## LLM (chat assistant)

Used by `POST /api/v1/chat` to read free-text intake and write the assistant's
reply. Any OpenAI-compatible endpoint works. **If the LLM is unset or
unreachable, chat silently falls back to scripted replies** — check
`llm_used` in the `/api/v1/chat` response (note: it reports that the LLM is
*configured*, not that the last call succeeded).

| Variable | Default | Purpose |
|---|---|---|
| `LLM_ENABLED` | `true` | Master switch. `false` forces the scripted fallback. |
| `LLM_BASE_URL` | *(unset — LLM off)* | Endpoint base, including `/v1`. Ours: `https://llm.arahim.dev/v1`. |
| `LLM_MODEL` | `qwen` | Model name the server serves. Ours: `qwen3.6-35b-a3b` (list with `GET <base>/models`). |
| `LLM_API_KEY` | `none` | Bearer key. `none` for an unauthenticated self-hosted server. Server-side only — never sent to the browser. |
| `LLM_REASONING` | `false` | Qwen "thinking" mode. Keep `false`: hidden reasoning eats the token budget and can return empty replies. |
| `LLM_MAX_TOKENS` | `800` | Max tokens per reply. |
| `LLM_TIMEOUT_S` | `30` | Seconds before a call is abandoned and chat falls back. |

## Deployment & tenancy

| Variable | Default | Purpose |
|---|---|---|
| `DEPLOYMENT_MODE` | `single_tenant` | `single_tenant` \| `pool` \| `silo`. |
| `DATABASE_URL` | *(unset — SQLite)* | A `postgres://` / `postgresql://` DSN switches to Postgres with row-level security. See `POSTGRES_RLS.md`. |
| `ESAP_GPU_POOL` | `1` | GPU count shown on the ops console's Global config page. Informational. |

## Demo & development switches

Keep these at their production values on any real deployment.

| Variable | Default | Production | Purpose |
|---|---|---|---|
| `ESAP_DEMO_PICKER` | `true` | `false` | Shows the "sign in as any role" demo accounts on the login page. |
| `ESAP_DEMO_ALL_ACCESS` | `false` | `false` | One platform account with every permission and no break-glass. **Never enable in production.** |
| `ESAP_SUPERUSER_EMAIL` | `superadmin@esap.health` | — | The account `ESAP_DEMO_ALL_ACCESS` applies to. |
| `ESAP_ALLOW_PREFILL` | `false` | `false` | Enables `GET /api/v1/cases/{hadm_id}/prefill` (non-production entitlement). |
| `ESAP_SSO_DEV` | `false` | `false` | Built-in dev SSO issuer and `POST /auth/sso/dev-login`, for testing SSO without a real IdP. |
| `NPI_VERIFY_ONLINE` | `false` | optional | Also check NPI numbers against the public CMS NPPES registry (the offline checksum always runs). |

## Ready-to-copy setups

### Local development

```env
MODEL_MODE=stub
ESAP_DB_PATH=esap.db
ESAP_SEED_PATH=seed/seed.json
ESAP_CORS_ORIGINS=http://localhost:5175,http://127.0.0.1:5175
ESAP_ALLOW_PREFILL=false

LLM_ENABLED=true
LLM_BASE_URL=https://llm.arahim.dev/v1
LLM_MODEL=qwen3.6-35b-a3b
LLM_API_KEY=none
LLM_REASONING=false
LLM_MAX_TOKENS=800
LLM_TIMEOUT_S=30
```

### Production (`/home/mubasshir/esap-backend/.env` on `esap-prod-01`)

```env
MODEL_MODE=stub
ESAP_DB_PATH=esap.db
ESAP_SECRET=<long random value>
ESAP_CORS_ORIGINS=https://esap-intelligent-ai-healthcare-r6cz.vercel.app
ESAP_ALLOW_PREFILL=false
ESAP_DEMO_ALL_ACCESS=false

LLM_ENABLED=true
LLM_BASE_URL=https://llm.arahim.dev/v1
LLM_MODEL=qwen3.6-35b-a3b
LLM_API_KEY=none
LLM_REASONING=false
LLM_MAX_TOKENS=800
LLM_TIMEOUT_S=30
```

Then `systemctl restart esap-backend`, and verify:

```bash
curl https://esap-api.159-195-83-232.sslip.io/readyz        # status ok, model_mode
# sign in, then POST /api/v1/chat — expect "llm_used": true
```

## Frontend (for reference)

The frontend has one build-time variable, set in Vercel project settings:

| Variable | Default | Purpose |
|---|---|---|
| `VITE_API_BASE` | `http://localhost:8000` | ESAP API the browser calls. Production: `https://esap-api.159-195-83-232.sslip.io`. Baked in at build time — **redeploy after changing it**. |

The frontend never talks to the LLM directly; only the backend does.
